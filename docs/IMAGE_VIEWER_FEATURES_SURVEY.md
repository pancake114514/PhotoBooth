## 八、对 Photobooth 项目的功能优先级建议

基于「实现成本低、用户体验提升明显」的原则，结合 Photobooth 现有架构（Electron + React + TypeScript + SQLite），推荐以下功能按优先级实施：

### P0 — 低成本高频用，强烈推荐

| 功能 | 理由 |
|------|------|
| 键盘翻页浏览 (Space/PgDn/PgUp/Home/End) | 看图核心交互，几乎零成本实现 |
| Ctrl+滚轮缩放 / 滚轮翻页 | Electron 原生支持，体验提升巨大 |
| 双击全屏切换 | 一行代码实现 |
| Tab 切换 EXIF 信息面板 | 已有 EXIF 数据，仅需 UI 切换 |
| 复制原图到剪贴板 (Ctrl+C) | Electron clipboard API 直接支持 |
| 复制缩放后图片到剪贴板 (Ctrl+Alt+C) | canvas 截取后写入剪贴板 |
| Ctrl+Enter 在资源管理器中定位 | Electron shell.showItemInFolder |
| 设为桌面壁纸 | Electron 可调用系统 API |
| Delete 移入回收站 / Shift+Delete 永久删除 | shell.beTrash + fs |
| 文件信息覆盖层（文件名/尺寸/缩放比例） | 状态栏已有数据，仅需浮层 UI |

### P1 — 中等成本，体验显著提升

| 功能 | 理由 |
|------|------|
| 全屏四角弹出工具（EXIF/缩略图导航/工具栏） | 全屏模式已有，添加 hover 触发面板 |
| 幻灯片播放 + 间隔/随机/循环设置 | 定时器 + Transition 即可 |
| 书签 / 收藏位置 | SQLite 存储路径列表，切换时导航 |
| 跨文件夹连续浏览 | 已有多文件夹管理，扩展翻页逻辑即可 |
| 快捷复制/移动到指定文件夹 | 预设路径 + fs.copy/move |
| 批量格式转换（选中多张 → 导出为指定格式） | 已有 sharp 依赖，扩展导出逻辑 |
| 批量重命名（模板通配符） | 字符串模板替换 + fs.rename |
| 始终置顶 | Electron BrowserWindow setAlwaysOnTop |
| 缩略图导航条（全屏模式） | 已有缩略图缓存，添加横向条组件 |
| 颜色筛选搜索 | 已有 sharp，可计算主色调存储 |
| 跳过 N 张翻页 (Ctrl+PgDn/PgUp) | 翻页逻辑扩展，索引跳跃 |
| 固定缩放级别 | 全局状态锁定缩放比例，翻页时保持 |
| 标签 / 评分 / 色标 + 组合筛选 | SQLite 扩展字段，已有星级收藏基础 |

### P2 — 成本较高，可选实现

| 功能 | 理由 |
|------|------|
| 双图对比浏览 | 需要双视图组件 + 同步缩放滚动逻辑 |
| 直方图显示 | 需逐像素计算 RGB 分布 |
